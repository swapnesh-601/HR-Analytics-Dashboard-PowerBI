# HR Analytics Dashboard 📊

## 📌 Project Overview
The **HR Analytics Dashboard** is designed to help organizations analyze employee data and derive actionable insights to improve **employee performance** and **employee retention** by identifying key factors contributing to **attrition**.

This project focuses on transforming raw HR data into meaningful visual insights using an interactive dashboard.

---

## 🎯 Objective
To help an organization:
- Improve employee performance  
- Improve employee retention  
- Reduce employee attrition  

by creating an interactive **HR Analytics Dashboard**.

---

## 🛠️ Tools & Technologies Used
- **Power BI**
- **CSV Dataset**
- **Data Cleaning & Modeling**
- **Basic DAX Measures**
- **Data Visualization Techniques**

---

## 📂 Dataset
- **File Name:** `HR_Analytics.csv`
- **Data Includes:**
  - Employee demographics
  - Job roles and departments
  - Salary slabs
  - Years at company
  - Attrition status
  - Job satisfaction ratings

---

## 📊 Key KPIs
- Total Employees  
- Number of Attritions  
- Attrition Rate (%)  
- Average Employee Age  
- Average Salary  
- Average Years at Company  

---

## 📈 Visualizations Used
The dashboard includes the following Power BI visuals:

- **Cards**
- **Matrix**
- **Stacked Column Chart**
- **Stacked Bar Chart**
- **Donut Chart**
- **Treemap**
- **Area Chart**
- **Bar Chart**
- **Slicer (Department-wise filtering)**

---

## 🔍 Insights Generated
- Higher attrition observed in lower salary ranges  
- Employees with fewer years in the company show higher attrition  
- Certain job roles and age groups have higher attrition rates  
- Gender and education background impact attrition trends  

These insights help HR teams take **data-driven decisions** to improve workforce retention.

## ▶️ How to View the Dashboard
1. Download the Power BI file from the `dashboard/` folder
2. Open `HR_Analytics_Dashboard.pbix` using **Power BI Desktop**
3. Use slicers to filter department-wise insights
4. Analyze attrition trends across age, salary, role, and tenure
